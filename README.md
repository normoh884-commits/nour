# Handwritten Digit Recognition ✍️🔢

## 📌 وصف المشروع (Project Description)
هذا المشروع يعتمد على التعلم العميق (Deep Learning) لبناء شبكة عصبية اصطناعية (ANN) قادرة على التعرف على الأرقام المكتوبة بخط اليد من 0 إلى 9.
تم استخدام مجموعة بيانات MNIST الشهيرة لتدريب النموذج على قراءة الصور بالأبيض والأسود.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Python**
- **TensorFlow & Keras** (لبناء وتدريب الشبكة العصبية)
- **NumPy** (للتعامل مع المصفوفات)

## 🚀 كيفية التشغيل (How to Run)
1. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
2. قم بتشغيل سكريبت التدريب (سيقوم السكريبت بتحميل بيانات MNIST تلقائياً):
   ```bash
   python digit_recognition.py
   ```
   
## 🧠 تفاصيل النموذج (Model Details)
- **Flatten Layer**: لتحويل مصفوفة الصورة (28x28) إلى خط واحد من الأرقام (784 بيكسل).
- **Dense Layer (ReLU)**: لاستخراج الأنماط المعقدة.
- **Output Layer (Softmax)**: لإعطاء نسبة احتمالية لكل رقم من 0 إلى 9.

# Email Spam Detection 📧

## 📌 وصف المشروع (Project Description)
هذا المشروع يهدف إلى بناء نظام يصنف رسائل البريد الإلكتروني إلى رسائل مزعجة (Spam) أو رسائل عادية (Ham) باستخدام تقنيات معالجة اللغات الطبيعية (NLP) وتعلم الآلة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Python**
- **Pandas** (لمعالجة البيانات)
- **Scikit-Learn** (لبناء وتدريب نموذج تعلم الآلة واستخراج الميزات باستخدام TF-IDF)

## 🚀 كيفية التشغيل (How to Run)
1. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
2. قم بتشغيل سكريبت التدريب:
   ```bash
   python spam_detection.py
   ```
   
## 📊 التقييم (Evaluation)
تم التركيز في هذا المشروع على مقياس **Precision** لأن تصنيف رسالة هامة بالخطأ كرسالة مزعجة أسوأ من وصول رسالة مزعجة للبريد الوارد.

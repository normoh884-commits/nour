# Satellite Image Segmentation 🛰️🌍

## 📌 وصف المشروع (Project Description)
هذا المشروع يعتمد على التعلم العميق (Deep Learning) لبناء نموذج يقوم بتقسيم صور الأقمار الصناعية (Image Segmentation) وتلوين كل "بيكسل" بناءً على فئته (مثل: طرق، مباني، أراضي زراعية، مسطحات مائية). 

## 🧠 معمارية النموذج (Model Architecture)
تم استخدام معمارية **U-Net** الشهيرة، والتي تتكون من:
1. **Encoder (المسار التنازلي):** لاستخراج الميزات (Features) وتقليل حجم الصورة.
2. **Bottleneck:** الجزء الأعمق في الشبكة.
3. **Decoder (المسار التصاعدي):** لتكبير الصورة وإعادتها لحجمها الأصلي مع استخدام (Skip Connections) للحفاظ على تفاصيل الحواف ومكانها الدقيق.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Python**
- **TensorFlow & Keras** (لبناء معمارية U-Net)
- **NumPy** (للتعامل مع المصفوفات)

## 🚀 كيفية التشغيل (How to Run)
1. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
2. قم بتشغيل سكريبت التدريب:
   ```bash
   python unet_segmentation.py
   ```
   
## 📊 التقييم (Evaluation - IoU)
في هذا النوع من المشاريع، لا نعتمد على دقة النموذج (Accuracy) بشكل أساسي بسبب مشكلة (Class Imbalance) في صور الأقمار الصناعية. بدلاً من ذلك، المقياس الأهم هو **IoU (Intersection over Union)** لضمان أن التلوين يتطابق تماماً مع المكان الحقيقي.
